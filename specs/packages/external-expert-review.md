# external-expert-review: 外部专家安全报告评审

## 意图

使管理员和三位外部专家完成一份安全报告的上传、独立邀请、评审签署及状态汇总，采用 [DR-001](../decisions/001-independent-expert-review.md) 的独立评审机制。
本包主体为管理员、三位受邀专家和评审系统。

## 外部行为

### external-expert-review-1

当管理员执行报告上传与评审发起流程，系统应按下列顺序建立一份报告对应三位不同外部专家的独立评审任务：

1. 保存管理员上传的报告，返回上传成功结果与可读取的报告标识；上传失败时提示失败，不创建可发起评审的报告。
2. 仅在报告上传成功且可读取、恰好填写三位不同专家的姓名与有效联系方式后允许发起，否则提示原因且不创建邀请。
3. 为三位专家分别创建绑定同一报告和各自身份的独立邀请及任务，初始个人状态为待评审，整体状态为进行中。
4. 向各自联系方式分别发送邀请，记录每份邀请的发送结果；失败时明确标记失败，不能显示为已送达。
5. 有效邀请仅允许对应专家读取该报告及自己的意见、签署和状态，拒绝无效邀请与跨专家任务访问，不展示其他专家意见与签名。

业务编号：EER-001（报告上传与专家邀请）

### external-expert-review-2

给定专家持有有效的独立评审邀请 [[external-expert-review-1](#external-expert-review-1)]，当专家提交评审签署流程的操作，系统应按以下判定完成该专家自己的评审任务：

| 操作与条件 | 系统结果 |
| --- | --- |
| 提交空白意见 | 拒绝提交，保持待评审 |
| 提交非空意见 | 保存该专家意见，个人状态为待签署 |
| 无意见时请求签署 | 拒绝签署，不得标记完成 |
| 有意见但未明确确认或无签署人姓名 | 拒绝完成签署，保持待签署 |
| 专家确认所提交意见并以本人姓名签署 | 同时保存意见、确认结果、签署人和签署时间，成功后将个人状态更新为已完成 |
| 保存签署记录失败 | 提示失败，保持待签署，不得标记完成 |
| 重复提交已完成任务 | 返回已有完成结果，不重复计数或覆盖签署记录 |

业务编号：EER-002（专家评审与签署）


### external-expert-review-3

给定报告已建立三位专家的独立任务 [[external-expert-review-1](#external-expert-review-1)]，当任务状态发生变更或管理员查看汇总，系统应根据已持久化的个人完成状态 [[external-expert-review-2](#external-expert-review-2)] 展示三位专家各自状态并计算整体状态：

| 已完成的不同专家数 | 整体状态 |
| --- | --- |
| 0 | 进行中 |
| 1 | 进行中 |
| 2 | 进行中 |
| 3 | 已完成 |

业务编号：EER-003（评审完成状态汇总）


## 验证

### external-expert-review-4

给定管理员与三位不同专家及可用的实际邀请通道，当执行上传及邀请的系统验收，验证应使用以下用例矩阵断言上传及独立邀请流程 [[external-expert-review-1](#external-expert-review-1)]：

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| V01 | 上传报告后从专家入口读取 | 文件与上传内容一致 |
| V02 | 模拟上传保存失败后发起 | 显示失败，无法发起 |
| V03 | 无报告、少于或多于三人、重复专家或缺失联系方式时发起 | 拒绝并提示原因，不创建邀请 |
| V04 | 成功上传后指定三位专家发起 | 三位专家在实际通道各收到一份独立邀请，分别可打开自己的任务 |
| V05 | 使用无效邀请或尝试访问他人任务 | 访问被拒绝，无法读取或修改他人意见与签名 |
| V06 | 其中一路邀请发送失败 | 对应发送结果显示失败，不能声称三位均收到 |

### external-expert-review-5

给定三位专家持有各自有效邀请，当分别执行评审签署的系统验收，验证应断言个人完成门槛 [[external-expert-review-2](#external-expert-review-2)]：

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| V07 | 提交空白意见或无意见时签署 | 拒绝，个人任务不完成 |
| V08 | 保存非空意见但不签署 | 意见独立保存，状态待签署 |
| V09 | 未确认意见或缺失姓名时签署 | 拒绝完成，保持待签署 |
| V10 | 确认本人意见并签署 | 保存意见、确认、姓名与签署时间，个人已完成 |
| V11 | 签署保存失败 | 不标记完成，提示失败 |
| V12 | 重复提交已完成签署 | 原记录不变，不新增完成计数 |

### external-expert-review-6

给定同一报告的三个真实独立任务，当依次完成零、一、二、三位专家的签署并刷新汇总页面，系统验收应断言每位专家状态与持久化记录一致、完成数恰为不同已完成专家数，整体状态依次为进行中、进行中、进行中、已完成 [[external-expert-review-3](#external-expert-review-3)]。

验收编号：V13（0/3）、V14（1/3）、V15（2/3）、V16（3/3）
